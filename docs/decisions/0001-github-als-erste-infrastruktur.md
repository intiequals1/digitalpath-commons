# 0001 – GitHub als erste Infrastruktur des Netzwerks

- **Status:** angenommen
- **Datum:** 25. Oktober 2026
- **Geltungsbereich:** Pilotphase des Dialectical Collaboration Network
- **Bezug:** Konzeptentwurf [Dialectical Collaboration Network](https://www.claudiu.at/digitalpath-dialectical-collaboration-network), Abschnitt 8

## Kontext

Das Netzwerk braucht einen Ort für offene Diskussionen, konkretisierte Probleme, Überblick und begründete Entscheidungen. Eine eigene Plattform zu entwickeln, wäre für die Pilotphase zu aufwendig.

## Entscheidung

Die Pilotphase nutzt bestehende Werkzeuge: GitHub Discussions für offene Fragen, GitHub Issues mit der Vorlage „Dialektisches Issue“ für konkrete Probleme, das Projektboard des Digitalpath-Projektlabors für den Überblick und Decision Records in diesem Repository. Konkrete Entwicklungen bleiben in eigenen Projekt-Repositories.

## Begründung

Der Konzeptentwurf schlägt vor, zunächst auf bestehenden Werkzeugen aufzubauen. GitHub trennt offene Diskussionen von konkreter Aufgabenverfolgung und ist für die bestehenden Projekt-Repositories bereits im Einsatz.

## Verworfene Alternativen

- Eigene Plattform: für die Pilotphase zu aufwendig.

## Dissens

Keiner dokumentiert. Offen ist, wie Personen ohne GitHub-Konto gleichberechtigt teilnehmen; bis zur Governance v0.1 gilt der Weg per E-Mail.

## Überprüfung

In Woche 8 der Pilotphase, zusammen mit der Entscheidung über die Fortführung.
